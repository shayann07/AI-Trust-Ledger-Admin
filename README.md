# AI Trust Ledger Admin App

This repository contains the **Admin application for AI Trust Ledger**, an Android-based system designed to manage ledger entries for trust accounts using AI. The admin app allows administrators to oversee user accounts, review and approve ledger transactions, and configure system settings.

## Features

- **Admin dashboard**: Provides an overview of ledger activity and system status.
- **User management**: View, add, edit, and remove user accounts.
- **Ledger transaction management**: Review and approve ledger entries submitted by users.
- **Authentication**: Secure login for administrators.
- **Notifications**: Get real-time notifications of pending approvals.
- **Integration**: Connects to backend services via REST APIs or Firebase.

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download dependencies.
4. Update API endpoints or Firebase configuration in your `local.properties` or environment files.
5. Build and run the app on an Android device or emulator.

## Technologies

- Kotlin and Java (Android app)
- Jetpack libraries (Compose/UI, LiveData, ViewModel)
- Firebase / RESTful APIs
- Gradle build system
